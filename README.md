# 谜序 Mixu

**记住每一个线索，推理留给你。**

这是谜序的**唯一入口仓库**：克隆它，就得到了全部开源部分。每个组件仍在自己的仓库里
维护（独立许可、独立历史、可被别的项目直接复用），这里只负责把它们按固定提交挂载起来。

> 目前处于**文档与架构阶段**：下面写的是设计目标，不是已经发布的功能。

## 拿到代码

```sh
git clone --recurse-submodules https://github.com/mixu-app/mixu.git
cd mixu
just update        # 已克隆但忘了 --recurse-submodules 时补挂载
just check         # markdown 门禁 + submodule pin 一致性
```

已经克隆过、想同步到最新固定提交：

```sh
git pull && just update
```

## 仓库里有什么

| 目录 | 内容 | 许可 |
|---|---|---|
| `client/` | Android/KMP 客户端：阅读器与案情板 | MPL-2.0 |
| `graph/` | 时序叙事图：模型、投影、查询 | Apache-2.0 |
| `spoiler/` | 知识边界过滤（防剧透） | Apache-2.0 |
| `renderer/` | Compose Canvas 图谱渲染 | Apache-2.0 |
| `contracts/` | 叙事图格式、HTTP 契约、错误码 | Apache-2.0 |
| `fixtures/` | 版权干净的剧透回归语料 | CC0-1.0 |
| `website/` | 落地页（bun-only 静态站 + 中文文案） | Apache-2.0 |

## 规则：挂载点只读

- 挂载目录是**只读**的。改代码请到对应仓库改，然后把这里的 pin 挪到新提交。
- 不要用符号链接替换挂载点，不要让 pin 跟随分支；`just pins` 会在 CI 与本机报错。
- 想在别的项目里复用某个组件（比如 `graph`），直接用它自己的仓库，不必拉这个入口仓库。

## 我们相信

- **不主动剧透。** 案情板按阅读进度做确定性过滤，并且用可失败的回归测试守着这条线。
- **不强制注册。** 导入、阅读、书签、笔记、已下载的图包，离线可用，不登录也能读完一本书。
- **声称不是事实。** 证词、旁白、推断、后来的确认，在界面里始终分得开。
- **只帮记忆，不替推理。** 不主动给嫌疑人排序，不替读者解谜。
- **可导出，可撤回。** 你的笔记和标注属于你。
